# Design System

## 1. Overview

### Purpose

Describe the visual design standards and UI consistency rules for Sleep Optimizer.

### Scope

- Colours
- Fonts
- Spacing
- Components
- UI design
- Navigation
- Accessibility

### 2. Design Philosophy

### Keywords

- Modern
- Clean
- Minimal
- Night-friendly
- Student-focused

### Design goals

- Make sleep planning simple.
- Reduce cognitive load.
- Encourage healthy sleep habits.
- Keep interfaces consistent.

## 12. Navigation

## 13. Feedback

### Loading

Show while calculation is in progress.

### Success

Show after successful calculation.

### Warning

Show for non-critical issues.

### Error

Show when calculation fails.

### Empty

Display when no history exists.

## 14. Accessibilty

- Minimum readable font size.
- Sufficient color contrast.
- Buttons should be easy to tap.

## 15. Design Consistency

- Use consistent spacing.
- Use consistent button styles.
- Reuse existing components whenever possible.
- Avoid creating duplicate components.

## 16. Responsive rules

Phone Width

Support common mobile screen sizes.

Portrait

Primary orientation.

Landscape

Optional.

Support Android phones.

Minimum width:
320 px

Recommended width:
360–430 px

## 17.Future Improvements

- Tablet layout
- Landscape mode
- Enhanced Dark Theme
- Material You
- UI animations

## 18.Design Constraints

- Avoid unnecessary animations.
- Avoid complex layouts.
- Prioritize readability over decoration.
- Keep every screen focused on one primary task.
